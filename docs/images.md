# 图片迁移适配

## 写法

这是针对旧笔记的 Obsidian 图片嵌入兼容模块。PNG、SVG、JPG/JPEG、GIF、WebP、BMP、AVIF 均可识别。

| 写法 | 显示 |
| --- | --- |
| `![[图片.png\|C\|500]]` | 居中，宽 500 px |
| `![[图片.svg\|500\|C]]` | 居中，宽 500 px |
| `![[图片.jpg\|L\|320]]` | 左对齐，宽 320 px |
| `![[图片.png\|320\|R]]` | 右对齐，宽 320 px |
| `![[图片.png\|500]]` | 默认居中，宽 500 px |
| `![[图片.svg\|R]]` | 右对齐，原始大小 |
| `![[图片.png]]` | 默认居中，原始大小 |

位置字母不区分大小写。大小为正整数，单位 px；保持图片比例，并限制在正文可用宽度内。
暂不支持 `500x300`、百分比、PDF/音频/笔记嵌入。文件名不能包含 `|` 或 `]]`。
代码块、行内代码和转义的图片标记由 Typora 原生解析器跳过。

模块通过原生图片组件显示图片，编辑图片源文本时保留 `![[...]]` 原始写法。
调整旧图片时编辑 `C/R/L` 与数字；Typora 原生的“缩放图片”等操作面向标准图片语法，
可能将图片转为标准 Markdown 或 HTML，不保证保留这组自定义参数。

## 路径查找

1. 当前笔记目录下的文件或相对路径。
2. Obsidian 库根目录下的路径；从当前笔记向上寻找 `.obsidian` 文件夹。
3. Typora 配置的图片根目录。
4. 只有文件名或路径尾部时，在库内异步查找匹配的图片。

没有 `.obsidian` 时使用 Typora 当前打开的文件夹；没有打开文件夹时使用当前笔记目录。
隐藏目录、`node_modules` 和符号链接目录不会被递归扫描。首次附件索引完成后会重绘相关图片。
库内有多个同名文件时，请改成 `![[附件/图片.png|C|500]]` 等明确路径。
索引缓存 30 秒；新附件优先使用明确的相对路径。

## 新图片沿用 Typora

拖入、粘贴或插入的新图片，继续由 Typora 生成标准 `![说明](路径)`。
在“偏好设置 → 图像”中按自己的习惯选择复制图片到指定路径、优先使用相对路径等选项。
推荐随笔记保存的相对目录，例如 `./assets`。模块不拦截拖放或剪贴板，不修改这组偏好设置。

参考：Typora 官方图片说明 https://support.typora.io/Images/

## 导出与边界

通过公共内联解析器和原生 HTML 导出保留图片宽度与位置；输出为带尺寸、边距的标准 `<img>`。
后台源码检查与真实 Typora 使用效果是不同的检查范围；此版本尚未在正在工作的 Typora 窗口内验证。
Pandoc 等直接读取原始 Markdown 的导出流程不经过这个模块，不会自动转换 `![[...]]`。
Typora 更新可能改变内部图片解析器，需要重新适配。

安装更新后重启 Typora，再打开 `examples/images.md` 查看示例。
